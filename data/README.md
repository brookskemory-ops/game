# data/

All game content lives here as data files — **content is data, not code** (see
`DEVELOPMENT_PLAN.md` §1.3). Built out in Phase 2/3.

- `characters/` — one resource per hero: stats, starting weapon, passive, unlock condition, story-arc id
- `weapons/` — weapon definitions: damage, cooldown, projectile pattern, evolution target
- `waves/` — per-stage spawn tables: what spawns, when, how many
